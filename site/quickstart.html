QUICKSTART

三步开始

把 skill 装进 Codex，然后直接用自然语言提需求。

1

克隆到 Codex 的 skills 目录

项目级（仅当前项目可用）或用户级（所有项目可用），任选其一：

# 项目级
git clone https://github.com/joshua-zyy/tech-story-comic.git \
  <你的项目>/.codex/skills/tech-story-comic

# 用户级
git clone https://github.com/joshua-zyy/tech-story-comic.git \
  ~/.codex/skills/tech-story-comic

下一轮对话即可使用。

2

确认环境

  • 带内置 imagegen 的 Codex 运行环境（唯一支持的生图后端）
  • bun 或 npx（仅最终 PDF 合并步骤需要）
3

用自然语言提需求

把 Redis 分布式锁做成 8 页技术讲解漫画，面向准备秋招的 Java 学生

skill 会先完成主题分析（学习目标 → 困境 → 概念链），与你确认方案后再生成分镜和图片。首次使用会询问少量默认项（水印、画风、语言），保存在 .tech-story-comic/EXTEND.md。

部分执行与改页：

/tech-story-comic content.md --storyboard-only   # 只要分镜
/tech-story-comic comic/my-topic/ --regenerate 3,5  # 重画第 3、5 页
OUTPUT

你会得到什么

产物保存在你项目的 comic/{topic-slug}/ 目录，每一步都有可复现的中间文件。

comic/redis-distributed-lock/ ├── analysis.md # 学习目标、困境、概念链 ├── storyboard.md # 每页故事层 + 台词计划 ├── characters/ # 角色设定 + 参考图 ├── prompts/NN-page-*.md # 逐页提示词（可复现记录） ├── NN-page-*.png # 成页 └── redis-distributed-lock.pdf # 最终漫画
